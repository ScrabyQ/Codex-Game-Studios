# Documentation work

For architecture ADRs, consult `.agents/docs/templates/architecture-decision-record.md` and the preserved upstream `docs/CLAUDE.md` as source guidance: include title, status, context, decision, consequences, ADR dependencies, engine compatibility and addressed GDD requirements. Follow Proposed → Accepted → Superseded; do not renumber existing TR registry IDs. Preserve the control manifest's version and review architecture changes with the applicable available workflow.

For engine APIs, resolve the selected engine and consult `docs/engine-reference/<engine>/VERSION.md` and its relevant reference before relying on signatures. This directory scope is not a substitute for selecting other matching path rules.
