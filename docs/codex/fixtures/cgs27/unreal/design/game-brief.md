# Charge Beacon
A disposable 2D UI fixture to verify a cross-engine studio workflow. Target: Windows local QA; Godot compatibility rendering keeps a possible web export viable, but export is not configured.
## MVP
1. Charge Beacon HUD — display three initial charges from data; spend one per button activation; refuse below zero; disable spending when empty; reset to configured initial count. Visible labels and buttons must fit an 800x480 viewport.
## Boundaries
No networking, saving, store, art assets, release or external writes. Timing/feel/accessibility usability require a human playtest and are outside the closure claim.
