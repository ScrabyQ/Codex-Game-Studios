# Design work

Resolve `modes.workflow` before assessing a GDD: full requires all eight sections; standard requires Overview, Detailed Rules, Edge Cases, Dependencies and Acceptance Criteria, plus Formulas when math applies; minimal uses `design/game-brief.md`. Detailed Design and Detailed Rules are equivalent headings. See `design/CLAUDE.md` and `.claude/docs/workflow-modes.md` for the full source guidance.

Use `design/gdd/[system-slug].md` and update `design/gdd/systems-index.md` when adding a GDD. Keep project-wide accessibility requirements at `design/accessibility-requirements.md`. Review GDDs and UX specifications using the relevant available workflow; where a Codex skill is not yet adapted, record that limitation rather than claim it ran. Select applicable path-specific rules in `.claude/rules/`.
